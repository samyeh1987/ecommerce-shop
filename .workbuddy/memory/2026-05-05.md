## 頁面空白問題修復 (14:52)

### 問題
- 首頁整個頁面變空白
- 用戶回報 Vercel 部署頁面完全無內容

### 根本原因
CSS 語言切換規則 `.lang-zh, .lang-en, .lang-th { display: none !important; }` 會匹配到 `<body class="lang-zh">` 本身，導致整個 body 被隱藏！

### 修復內容（Commit 6a76fbd）

1. **所有 9 個 HTML 頁面**（index-thai, products, product-detail, cart, checkout, login, account, order-detail, admin-thai）：
   - CSS 選擇器從 `.lang-zh, .lang-en, .lang-th` → `body .lang-zh, body .lang-en, body .lang-th`
   - 加上 `body.lang-zh { display: block !important; }` 確保 body 本身可見

2. **pages/js/index-thai.js**：
   - `switchLanguage()` 新增 `document.body.style.display = 'block'`
   - `initLanguageFromStorage()` 確保初始化時 body 可見

3. **pages/index-thai.html**：
   - 新增 `body.lang-zh, body.lang-en, body.lang-th { display: block !important; }` 規則

### 經驗教訓
- CSS class 選擇器 `.lang-zh` 會匹配任何帶此 class 的元素，包括 body
- 多語言切換的隱藏規則必須用後代選擇器（`body .lang-zh`）避免匹配 body 自身

## 頁面 404 問題修復 (14:59)

### 問題
- 點擊頁面連結出現 404 NOT_FOUND
- 不是數據庫問題，是 Vercel 路由問題

### 根本原因
頁面使用相對路徑（如 `products.html`），但 Vercel 的靜態文件在 `/pages/` 子目錄下，
通過 rewrite 訪問 `/` 時，瀏覽器解析相對路徑為 `/products.html`，無對應靜態文件和 rewrite 規則。

### 修復內容（Commit d9c34c6）

1. **vercel.json**: 新增通配 rewrite `/:path*.html` → `/pages/:path*.html`
2. **所有 HTML 頁面（11個）**: 導航 href 全部改為絕對路由路徑
   - `products.html` → `/products`，`cart.html` → `/cart` 等
3. **所有 HTML 頁面**: JS 資源路徑改為絕對路徑
   - `src="js/xxx.js"` → `src="/pages/js/xxx.js"`
   - `src="../js/xxx.js"` → `src="/js/xxx.js"`
4. **所有 JS 文件（8個）**: `location.href` 路徑同步修改
5. **auth.js**: redirect fallback 從 `account.html` 改為 `/account`

### 驗證結果
- `/` 首頁 ✅
- `/products` ✅
- `/cart` ✅
- `/login` ✅

### 經驗教訓
- Vercel rewrite 不改變瀏覽器 URL，相對路徑基於瀏覽器地址欄解析
- 多頁面靜態站部署到 Vercel 時，所有連結應使用絕對路徑
- 商品數據為空（0 products）是因為 Supabase 連線未配置，不是路由問題
- 每個帶 `lang-zh` class 的元素都會被隱藏，body 也不例外

## 商品詳情頁 404 修復（第二輪）(15:12)

### 問題
- 限時秒殺和熱銷商品點入仍出現 404
- URL 格式為 `/product?id=prod-3`（query string）

### 根本原因
vercel.json 只有 `/product/:id`（路徑參數格式，匹配 `/product/prod-3`），
但所有商品連結都用 query string 格式 `/product?id=prod-3`。
Vercel 找不到 `/product` 這個靜態檔案，也沒有對應的 rewrite 規則，回 404。

### 修復內容（Commit 2431c9b）
1. **vercel.json**: 新增兩條不帶 `:id` 的 rewrite 規則
   - `{ "source": "/product", "destination": "/pages/product-detail.html" }`
   - `{ "source": "/order", "destination": "/pages/order-detail.html" }`
2. 與原有的 `/product/:id` 和 `/order/:id` 規則並存，兩種格式都能正確路由

### 驗證結果
- `/product?id=prod-1` ✅ 200
- `/product?id=prod-3` ✅ 200
- `/product?id=prod-5` ✅ 200
- `/product?id=feat-1` ✅ 200
- `/order?id=ord-1` ✅ 200

### 經驗教訓
- Vercel rewrite 的 `:id` 只匹配路徑段，不匹配 query string
- 需要同時配置 `/product` 和 `/product/:id` 兩種格式，確保 query string 和 path param 都能路由
