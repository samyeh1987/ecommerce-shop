## 修复 index-thai.html 空白页面 Bug（15:10）

**问题**：用户反馈客户端 UI 预览显示空白页面。

**根因**：
1. JS 轮播脚本引用不存在的 `.carousel-indicator` 元素，导致 `indicators[i].classList` 报错，整个 `<script>` 块停止执行
2. 语言切换按钮的 active 状态恢复依赖 `event.target`，inline onclick 环境下 `event` 未正确传入
3. CSS 多语言 `display: none/inline-block` 规则被 Tailwind 工具类覆盖

**修复内容**（已覆写 `pages/index-thai.html`）：
- 轮播指示器改为 `.carousel-dot` class，加入空数组防御
- 语言切换改用按钮文字比对方式，不再依赖 `event` 对象
- 所有多语言 `display` 规则加 `!important`
- `localStorage` 操作包入 `try/catch`
- 箭头按钮和指示器 HTML 结构补充完整

**状态**：文件已更新，待用户确认预览是否正常。
